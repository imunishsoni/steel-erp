CodeIgniter 4 Architecture & On-Premise XAMPP Setup

Full Technical Documentation for Running the PHP/MySQL Heavy Steel Fabrication ERP

GitHub Repository
Local Development Setup (XAMPP / PHP 8.1+)
  1. Clone the repository:
    git clone https://github.com/imunishsoni/steel-erp.git
  2. Start XAMPP: Ensure Apache and MySQL modules are started in XAMPP Control Panel.
  3. Create Database:
    Open http://localhost/phpmyadmin, create database steel_erp, and import database/steel_erp.sql.
  4. Configure Environment:
    Copy .env.example to .env and update database credentials: 
    database.default.hostname = localhost
database.default.database = steel_erp
database.default.username = root
database.default.password = 
app.baseURL = 'http://localhost:8080/'
  5. Run CodeIgniter 4 Spark Server:
    php spark serve --port 8080
  6. Access in Browser: Open http://localhost:8080. Log in with:
    Username: admin | Password: admin123
Industrial Architecture & Indian Compliance
Indian Steel Fabrication Workflow:

1. Tender & Quotation: Estimation based on ISMB/ISMC standard rolling weights and plate cutting nested areas.

2. Material Inward & MTC: Heat-number level traceability mapped from SAIL / Tata / Jindal test certificates.

3. Shop Floor Stages: Oxy-Cutting → Fitment → SAW/SMAW Welding → NDT (UT/RT/DPT) → Blasting SA 2.5 → PU Painting.

4. Weighbridge & DC: Automatic tare and gross weighment recording for multi-axle trailers.

5. GST Billing: HSN 730890 (Structures of iron or steel) with 18% GST (CGST+SGST for intra-state, IGST for inter-state) and E-Way bill generation.

GitHub Pages Static Deployment:

This GitHub Pages build packages a zero-dependency, self-contained client-side single page app under /docs with pre-bundled Bootstrap 5, Chart.js, DataTables, and Select2 libraries, coupled with a GitHub Actions workflow (.github/workflows/deploy-pages.yml) for automatic deployment on push.
